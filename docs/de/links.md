# Ingress-Links

Nützliche Seiten für Ingress-Agenten. Dieselbe Liste ist auf der
[AgentTools-Website](https://agent-tools.elkuku.dev/links) und in der Android-App.

Um einen Link hinzuzufügen oder zu ändern, bearbeite
[docs/links.md](https://github.com/elkuku/AgentTools/edit/master/docs/links.md) und öffne einen
Pull-Request. Jeder Link wird einmal am Tag geprüft. Die Liste ist auf Englisch.
