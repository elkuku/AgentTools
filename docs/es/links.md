# Enlaces de Ingress

[sitio web de AgentTools](https://agent-tools.elkuku.dev/links) y en la app para Android.

Para añadir o cambiar un enlace, edita
[docs/links.md](https://github.com/elkuku/AgentTools/edit/master/docs/links.md) y abre un pull
request. Cada enlace se comprueba una vez al día. La lista está en inglés.
